# Academic Challenge Frontend

This repository now contains the frontend only for the Academic Challenge platform.

## Project Structure

- `frontend/` - Next.js (TypeScript) + Material UI website

## Quick Start

```bash
cd frontend
npm install
npm run dev
```

## Pages Implemented

- `frontend/src/app/page.tsx` - Homepage
- `frontend/src/app/competitions/page.tsx` - Competitions listing
- `frontend/src/app/competitions/[slug]/page.tsx` - Competition details

## Notes

- Backend has been intentionally removed from this repository.
- A separate repository can be used for FastAPI and database services.
